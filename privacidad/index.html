Aviso de privacidad

Este aviso explica de forma sencilla qué información recibe Pronoia Print cuando una persona solicita un presupuesto desde la web y cómo se utiliza.

1. Responsable

Julieta - Pronoia Print es responsable del uso de los datos enviados mediante el formulario. Para consultas, acceso, corrección o eliminación de información podés escribir a pronoia.print@gmail.com.

2. Información que se solicita

El formulario puede recopilar nombre, número de WhatsApp, email opcional, ciudad o provincia, producto, color, talle, cantidad, ubicaciones del estampado, instrucciones y el archivo de imagen o PDF que la persona decida adjuntar.

3. Para qué se utiliza

La información se usa únicamente para analizar la solicitud, preparar y responder el presupuesto, revisar la viabilidad del diseño, contactar a la persona interesada y, si acepta la propuesta, gestionar su pedido. No se utiliza para enviar publicidad sin autorización.

4. Diseños y archivos

Los archivos adjuntos se utilizan como referencia para el presupuesto y, cuando corresponda, para preparar el trabajo solicitado. No se publican en la galería ni se comparten con otros clientes sin autorización. Quien envía un archivo declara tener permiso para utilizarlo.

5. Consentimiento y proveedores tecnológicos

El envío se realiza con el consentimiento expreso de la persona, conforme a la Ley argentina 25.326 de Protección de los Datos Personales. Para operar la web pueden utilizarse proveedores de alojamiento, base de datos y almacenamiento que actúan como soporte tecnológico y pueden procesar información fuera de Argentina.

6. Conservación y seguridad

Los datos se conservan durante el tiempo necesario para responder la consulta, gestionar el eventual pedido y atender obligaciones aplicables. Después pueden eliminarse o anonimizarse. Pronoia Print aplica medidas razonables para restringir el acceso, aunque ningún sistema conectado a internet ofrece seguridad absoluta.

7. Tus derechos

Podés solicitar información sobre tus datos y pedir su acceso, actualización, rectificación o eliminación escribiendo a pronoia.print@gmail.com. La Agencia de Acceso a la Información Pública es el órgano de control de la Ley 25.326 y recibe consultas o denuncias relacionadas con la protección de datos personales.

8. Cambios en este aviso

Este aviso puede actualizarse si cambia el funcionamiento del formulario o la forma de gestionar los pedidos. La versión vigente será siempre la publicada en esta página.
